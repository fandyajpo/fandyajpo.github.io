# Influenzilla landing page

Static HTML, CSS, and JavaScript implementation scaffold based on the supplied Figma desktop/mobile layouts.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Structure

```text
index.html
css/index.css
images/
js/index.js
```

## Before submission

- Export and replace the CSS-generated image placeholders with the original image assets from the duplicated Figma file.
- Add the GA4 Measurement ID and GTM container snippet supplied for the test; confirm the Analytics page's exact event list before finalizing tracking.
- Verify the required desktop and iPhone SE viewport sizes in Edge and Firefox, and check the final page title.
- Update the page title if the required candidate display name differs from `Fandy Ahmad`.
